# МОГУ — Учусь • Говорю • Играю

Первый этап разработки приложения МОГУ.

## Главная страница

- Адаптивная главная страница для телефонов, планшетов и компьютеров.
- Основные разделы: «Я хочу сказать», «Учусь», «Мир вокруг меня», «Мои эмоции».
- Переключение интерфейса между русским, казахским и английским языками.
- Нижняя навигация: Главная, Прогресс, Родителям, Специалисту.
- PWA manifest и базовый Service Worker для кэширования оболочки приложения.

## Локальный запуск

Откройте проект через любой локальный статический HTTP-сервер или опубликуйте содержимое корня сайта на хостинге со статической раздачей. Для проверки офлайн-режима сначала откройте сайт по HTTPS, дождитесь регистрации Service Worker, затем отключите сеть и перезагрузите страницу.

## Текущий объём

Это главная страница и визуальный фундамент, а не завершённая версия всех разделов. Карточки и нижняя навигация пока показывают сообщение о следующих этапах разработки. Функции МОГУ TALK, обучающие упражнения, кабинеты и профиль будут реализованы отдельно.
