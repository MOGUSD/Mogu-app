# Android APK — МОГУ

## Что собирается
GitHub Actions создаёт устанавливаемый Android APK из текущей веб-версии МОГУ через Capacitor. Сборка использует отдельную ветку `feature/android-apk` и не меняет `main`, production-сайт или Worker preview.

## Иконка
В процессе сборки исходный `assets/mogu-icon.svg` преобразуется в PNG высокого разрешения. Это сохраняет оригинальный фирменный логотип с фотографией девочки для иконки приложения и заставки.

## Получение APK
1. Откройте вкладку Actions репозитория.
2. Выберите workflow **Build МОГУ Android APK**.
3. Откройте успешный запуск.
4. Внизу страницы скачайте artifact **mogu-android-apk**.
5. Распакуйте архив — внутри будет `app-debug.apk`.

Это тестовая debug-сборка для личной установки и проверки, не публикационная подписанная сборка Google Play. Android может показать предупреждение при установке APK, скачанного не из Play Маркета.
